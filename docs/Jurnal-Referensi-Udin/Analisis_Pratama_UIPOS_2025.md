# Analisis Jurnal: Optimalisasi Proses Bisnis UMKM Melalui UI POS

## Informasi Publikasi
*   **Judul Jurnal:** Optimalisasi Proses Bisnis UMKM Melalui User Interface Sistem Point of Sale (Studi Kasus: Cireng Asgard)
*   **Penulis:** Rd Muhammad Sopian Putra Pratama, Franciskus Antonius Alijoyo, Efi Sofiah
*   **Tahun:** 2025
*   **Penerbit:** ZONAsi: Jurnal Sistem Informasi

## Analisis Konten
### 1. Tujuan Penelitian
Merancang *User Interface* (UI) sistem POS berbasis metode *Goal-Directed Design* (GDD) untuk meningkatkan efisiensi operasional UMKM kuliner.

### 2. Metodologi
Kualitatif (Observasi/Wawancara) -> GDD (Goal-Directed Design) -> Uji Usability menggunakan *System Usability Scale (SUS)*.

### 3. Temuan Utama
*   Pencatatan manual sering memicu hilangnya data, kesalahan input, dan *stock opname* yang tidak akurat.
*   Desain UI aplikasi POS yang berorientasi tujuan (GDD) menghasilkan kepuasan tinggi. Skor SUS pelanggan 86.33, tim operasional 86.43, dan manajerial 85.83 (Kategori *Excellent*).
