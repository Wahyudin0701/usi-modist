# Analisis Jurnal: Sistem Monitoring Kinerja Karyawan (Metode Prototyping)

## Informasi Publikasi
*   **Judul Jurnal:** Rancang Bangun Sistem Monitoring Kinerja Karyawan dan Penggajian Karyawan Konveksi berbasis web
*   **Penulis:** Dini Alawiyah, Rinda Cahyana
*   **Tahun:** 2025
*   **Penerbit:** Jurnal Algoritma

## Analisis Konten
### 1. Tujuan Penelitian
Merancang dan mengembangkan sistem berbasis *web* terintegrasi untuk memantau kinerja karyawan konveksi (FPN Collections) dan mengelola penggajian.

### 2. Metodologi
Menggunakan metode **Prototyping** dengan 5 tahap:
1. Communication
2. Quick Plan
3. Modeling Quick Design
4. Construction of Prototype
5. Deployment delivery & feedback.
Pengujian menggunakan metode *Black Box Testing*.

### 3. Temuan Utama
*   Aplikasi *web* berhasil menanggulangi pencatatan manual di buku besar, meminimalisasi ketidakakuratan perhitungan gaji, dan mengotomatisasi penilaian kinerja.
*   Hasil pengujian *Black Box* mencatat tingkat keberhasilan (*usability/acceptance*) sebesar 87,6% (kategori Sangat Baik).
